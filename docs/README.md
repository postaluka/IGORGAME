# Гра ІГОР

Влуч по літерах, що літають у біт музики, і склади слово **ІГОР** якомога швидше.

- 4 рівні складності: Легко, Нормально, Важко, Пекло. Що вищий рівень, то швидші літери і більше зайвих.
- Літери смикаються і спалахують на кожному ударі барабана.
- Таймер і таблиця рекордів (топ-10 для кожного рівня).
- Працює на комп'ютері й на телефоні.

## Як запустити у себе

Музика в браузері працює лише через сервер, тому просто двічі клацнути на `index.html` замало. Відкрий термінал у цій папці і виконай:

```bash
python3 -m http.server 8000
```

Потім відкрий у браузері http://localhost:8000

## Як викласти в інтернет (GitHub Pages)

1. Створи новий репозиторій на GitHub і залий туди цю папку.
2. У репозиторії відкрий **Settings → Pages**.
3. У **Source** вибери **Deploy from a branch**, гілку `main` і папку `/ (root)`, потім **Save**.
4. Приблизно за хвилину гра буде за адресою `https://<твій-логін>.github.io/<назва-репозиторію>/`.

## Таблиця рекордів

На Vercel таблиця спільна для всіх гравців. Її зберігає серверна функція `api/records.js` у базі Upstash Redis.
Щоб це запрацювало, у проєкті на Vercel відкрий **Storage**, натисни **Create Database**, вибери **Upstash Redis** (план Free) і підключи базу до проєкту, а потім зроби **Redeploy**.

Без бази (локально або на GitHub Pages) рекорди зберігаються в браузері кожного гравця.
